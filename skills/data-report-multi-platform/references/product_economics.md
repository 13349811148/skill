# 商品成本与毛利

本规则适用于商品日报，店铺日报口径不变。

成本列连续放在商品SKU之后：综合成本、产品成本、快递成本、其他均摊成本、平台费用，然后接活动价。删除原店铺费用和平摊管理费用，其余字段保留；SKU ID仍在最后。金额显示两位小数，计算保留原精度。

所有新增成本都是每件金额：快递成本固定2.1元/件，不按订单人数除回；其他均摊成本=到手价×16.7%；平台费用=到手价×0.7%。到手价仍为实收金额÷有效销量。综合成本=产品成本+快递成本+其他均摊成本+平台费用；毛利=到手价−综合成本；毛利率=毛利÷到手价。到手价为0时毛利率留空。

产品成本优先正式匹配，也使用已授权参考测算并标注来源。未匹配产品成本时，已知的快递、其他及平台成本可填写，但产品成本、综合成本、毛利、毛利率及净利润留空，不把缺失产品成本视为0。

净利润仍是整行总额，不能把单件毛利直接减当日推广费。净销售额及补贴已知时，净利润=净销售额−综合成本×有效销量−推广费用，等价于单件毛利×销量+总补贴−推广费用。不再另扣已删除的两项旧费用。营销资料缺失时不以0猜补贴；可填写单件综合成本、毛利和毛利率，净销售额及净利润继续留空。

空烧推广费没有有效销量，不计快递和按销售计提的费用：快递、其他、平台成本及毛利为0，毛利率与单件综合成本不适用并留空，净销售额为0，净利润为负推广费。保留可匹配的产品成本、商品信息和原空烧说明。

历史报表迁移只重排已有最终记录并应用本规则，不能改变已确认的订单排除、日期限制、销量、实收、推广分摊和date_notes。检测到未认识的表头、人工公式或重复业务键时停止，先核对；不要清空原文件。新增列后使用字段名定位数值、备注和标识格式，不使用旧I/Z/AH等固定位置。
