# 商品成本与毛利

本规则适用于商品日报，店铺日报口径不变。

“商品SKU”输出列改为“SKU编码”，紧接新增“SKU名称”，然后依次为综合成本、产品成本、快递成本、其他均摊成本、平台费用、活动价。删除原店铺费用和平摊管理费用，其余字段保留；SKU ID仍在最后。金额显示两位小数，计算保留原精度；日期为真实日期，格式固定yyyy-mm-dd。

SKU名称按成本表编码精确匹配“产品名称”（兼容“商品名称”）。组合装仅按组合装编码，货品按货品编码，不把子件表达式当成整套编码。匹配状态与成本金额不影响名称匹配：成本未匹配、名称明确时仍填名称。没有对应编码时名称留空，同编码不同名称时停止并核对。内部仍兼容原订单及营销表的商品SKU字段名，写出时使用SKU编码；历史业务键同样使用SKU编码。

所有新增成本都是每件金额：快递成本固定2.1元/件，不按订单人数除回；其他均摊成本=到手价×16.7%；平台费用=到手价×0.7%。到手价仍为实收金额÷有效销量。综合成本=产品成本+快递成本+其他均摊成本+平台费用；毛利=到手价−综合成本；毛利率=毛利÷到手价。到手价为0时毛利率留空。

产品成本优先正式匹配，也使用已授权参考测算并标注来源。未匹配产品成本时，已知的快递、其他及平台成本可填写，但产品成本、综合成本、毛利、毛利率及净利润留空，不把缺失产品成本视为0。

按用户再次确认，净利润=该行毛利−该行推广费用，直接相减，不乘销量、不加补贴，也不另扣费用。毛利已知即可计算净利润，不依赖净销售额或补贴是否齐全；毛利未知时净利润留空。推广费用原有空白表示无分配花费时，沿用0参与相减。缺营销资料仍将未知补贴和净销售额留空，不影响按此定义填写净利润。

空烧推广费没有有效销量，不计快递和按销售计提的费用：快递、其他、平台成本及毛利为0，毛利率与单件综合成本不适用并留空，净销售额为0，净利润为负推广费。保留可匹配的产品成本、商品信息和原空烧说明。

历史报表迁移只重排已有最终记录并应用本规则，不能改变已确认的订单排除、日期限制、销量、实收、推广分摊和date_notes。检测到未认识的表头、人工公式或重复业务键时停止，先核对；不要清空原文件。新增列后使用字段名定位数值、备注和标识格式，不使用旧I/Z/AH等固定位置。
