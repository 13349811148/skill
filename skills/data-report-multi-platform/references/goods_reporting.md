# 货品日报与利润汇总

- 来源为产品成本表“编码成本汇总”的精确编码：组合装编码→货品编码（组合内），单品名称使用产品名称，数量使用明确的×倍数；基础单位保持源表，不把一袋内几片自动当成几袋。
- 支持递归组合装，相同子件合并。子件数量×去退款去补单后的实际销售件数；不同SKU贡献同一货品时按日期、店铺、货品编码汇总。
- 单一货品数量为数值；多货品名称、数量同序换行。无有效销量/空烧推广不产生货品数量。缺货品定义、无名称、循环引用、无效倍数不能猜测，货品日报保留待拆分行和源SKU销量，并写独立核对日志。
- 货品表仅汇总实物数量和SKU来源贡献，不擅自分摊SKU销售额、快递费、推广费和利润；这些金额仍在商品日报，每个原业务键只计算一次。
- 店铺净利润=同日同店所有商品行净利润之和，包括空烧推广。存在未确认的缺失净利润则当天留空，记录缺失编码；经用户确认暂计0的行按0参与，并记录临时口径。商品生成失败不得用旧结果宣称完成新一日汇总。
- 美化使用分区色带、浅色日期分组、清晰字段行、冻结表头和负数红色；ID为文本，日期为真实Excel日期并显示yyyy-mm-dd。商品表22列、货品表8列、店铺表27列。
- 已有商品20/32列表头可备份迁移，未知表头/人工公式仍停止。新分区首行不得误当字段行。店铺原值保留、估算说明和人工填写列不因美化丢失。
