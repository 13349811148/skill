# 商品日报上传 WPS 在线文档

固定保存规则优先：见 [固定保存与历史迁移](report_archive.md)。现在上传固定商品总工作簿（按月子表），有已成功链接或交接记录 `previous_url` 时，更新同一在线文件/新版本，不每次新建。旧URL仅用于定位，不代表新内容上传成功。店铺月报由用户自行上传。

本流程由执行日报的代理在每次商品日报完成本地检查后继续执行，浏览器上传与 Python 计算分开。默认目的地是当前登录账号的“我的云文档”个人根目录；用户指定 WPS 文件夹时使用该文件夹。不改写已打开的其他表格，不把商品日报追加到店铺模板，不公开分享或扩大现有权限。

## 交接记录

入口 `scripts/build_report.py` 只在该平台生成进程成功退出且本次 XLSX 存在、完整时创建 `<商品日报名>.wps-upload.json`，输出 `WPS_UPLOAD_HANDOFF`。记录报告绝对路径、SHA-256、平台和状态。失败的平台不上传；多平台分别上传。仅店铺模式不创建交接。

- `pending`：本地完成，尚未验证上传。
- `login_required`：等待用户登录。
- `failed`：上传或工具受阻，可从现有文件重试。
- `uploaded`：已在 WPS 打开并验证对应文档，包含真实文档链接。

不要把密码、Cookie、验证码、令牌写入脚本、配置、日志或仓库。上传记录只保存在报表输出目录，不发布业务文件或在线文档链接到代码仓库。

## 浏览器步骤

1. 检查本次商品文件的日期、工作表、主要金额和推广费用核对已通过，随后使用可用的浏览器工具。优先沿用用户已经登录 WPS 的浏览器。无会话时打开官方入口 `https://www.kdocs.cn/`，使用实际页面入口导航，不猜上传 API 或读取浏览器凭据。
2. 若显示登录、扫码或验证码页面，保持页面，记录 `login_required`，向用户说明“请在已打开的 WPS 页面完成登录，完成后回复已登录”。登录过程由用户自行操作，不代填账号密码或验证码，不绕过安全验证。使用工具支持的 handoff 标记保留该页。等待期间保留 XLSX 和交接记录。
3. 用户完成登录后重新读取页面状态，继续上传同一个已经校验的文件，无须再次生成或请求重复上传确认。账号身份或目的地存在实际歧义时先澄清。
4. 在“我的云文档”（或用户明确指定的目录）查看上传文件是否已存在。相同文件哈希且交接已标成功时先验证已记录链接；成功可复用，失效则重试。若已存在同名文件，核对来源、日期和内容；不覆盖未知文件或默认接受替换。修订报告需要独立文件时给本次上传副本添加生成时间后缀，保留原文件。
5. 当前网页通常为“导入 → 上传文件”。先读当前 DOM/截图，点击导入后再读状态，确认“上传文件”菜单项后才等待 `filechooser` 并点击该菜单项；导入按钮本身可能只展开菜单。按浏览器工具的上传文档使用绝对路径设置文件。不要上传输出目录、原始订单、店铺日报、日志、预览或 JSON。
6. 等待实际文件成功状态或目录中出现新文件，打开该文件确认标题、日期、工作表和代表性金额匹配本地日报。取得浏览器实际显示的 `https://www.kdocs.cn/l/...` 文档地址，保持默认权限；获取可打开地址不要求创建公开分享链接。页面若只显示上传/转换中，尚不算完成。
7. 更新交接记录为 `uploaded`，最终同时交付本地 XLSX 与 WPS 链接。浏览器工具要求时保存成功截图作为证据，但不额外上传截图。

## 失败与续传

上传失败不删除本地报告、不重算、不声称已上传。先检查当前页面和目录有无文件，避免重试产生重复。文件选择器/上传工具失败时读取该工具提供的上传排障文档；需要用户开启扩展文件访问权限时说明准确操作，不能自动改变安全权限。可修复的原因解决后重试一次；仍失败则标记 `failed`，报告具体障碍和本地文件位置，等待用户处理后续传。

记录操作示例（`--url` 必须是此次浏览器验证过的实际链接，不得照抄示例或编造）：

```text
python scripts/wps_upload.py record --report <商品日报绝对路径> --status login_required --message 等待用户登录
python scripts/wps_upload.py record --report <商品日报绝对路径> --status failed --message <实际失败原因>
python scripts/wps_upload.py record --report <商品日报绝对路径> --status uploaded --url <实际WPS文档地址> --message 已打开核对日期工作表和金额
```

断点恢复已有文件可运行 `prepare --report <路径> --platform pdd`（天猫用 `tmall`），它校验 XLSX 并创建交接，不执行上传。记录成功状态前会检查本地哈希，防止上传后文件已改仍沿用旧链接；内容变更需重新准备并验证。
